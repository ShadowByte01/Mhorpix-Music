Installation & Troubleshooting Guide

Why did my APK automatically close on launch?

If an APK closes immediately upon opening, it is typically caused by one of two things:
1. Architecture (ABI) Mismatch: If you installed the armeabi-v7a (32-bit) build on a 64-bit-only phone (such as Google Pixel 7/8/9, Samsung Galaxy S24, or modern 64-bit OEM ROMs), Android will refuse to execute 32-bit native binaries and terminate. Solution: Install the Universal APK or the ARM64-v8a build.
2. Uncaught Background Thread Exception: In release v1.7.3, startup initialization for audio/canvas caching has now been hardened with bounded joins and exception safety guards to prevent lockouts and crashes.

How do I install the APK on Android?

1. Tap the Download Universal APK button above to download the file directly.
2. Once downloaded, open your notification shade or Files app and tap the .apk file.
3. If prompted, enable "Install unknown apps" for your browser in Android Settings.
4. Tap Install. Your existing songs, cached tracks, and settings will remain preserved.

Are these builds official and virus-free?

Yes! Mhorpix is 100% open-source. All APK and Windows packages are built directly from the source code hosted at github.com/ShadowByte01/Mhorpix-Music. The website downloads directly from the official GitHub Release CDN.
